# Caleb's Recipes Website Project

### What I've Done
* Built five pages:
    * Home
    * Peanut Butter Sandwich
    * Grilled Cheese Sandwich
    * Cooking Resources
    * Cooking Converter
* Added 600px media query so each page has a responsive layout.
* Added semantic HTML, alt text, larger font size, descriptive links, and larger mobile tap targets.
* Added consistent navigation, footer link, and CTA.
* Added meta descriptions and page titles.
* Added a resource page with external links.
* Added a page to convert different volume units with a form.

* Added responsive recipe images with srcset using multiple image sizes.
* Added image credits using Unsplash and Pexels attribution suggestions.
    * These websites license the images for free.
* Used the HTML/CSS validators and currently have no validation errors for any of the files.
